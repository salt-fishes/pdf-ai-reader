# 隐私说明

纸间（Paper Reader）是本地优先的 PDF 阅读器。阅读、搜索、高亮与扫描件文字识别默认都在本机完成。只有你明确选择的内容才会发给你配置的模型服务。

## 本地处理

PDF 文件不会上传。页面解析、文字层提取、搜索、高亮与 OCR 都在本机进行；关闭文档后，页面内容会从内存中释放。

以下内容也只保存在本机：

- 阅读位置、最近文档与界面偏好。
- 对话记录、引用与附件。
- 高亮与扫描件识别出的文字。
- 模型服务的 API Key、地址与允许使用的模型。
- 外部工具（Sciverse / MCP）的地址、请求头与访问 token。
- 下载到本机的 OCR 组件与模型。

## 发送给模型

只有以下内容会通过本机代理发给你配置的模型服务：

- 你选择的页码文本（当前页、全部页或页码范围）。
- 选中文字、跨页选择与引用。
- 整页截图、框选截图与上传的附件。
- 你的问题，以及对话历史窗口内的消息。

不会发送整份 PDF、未选择的页面、文件名或本地路径。云端是否保留请求内容由模型服务商的条款与隐私政策决定；纸间不做额外转发。

## 外部工具（可选）

如果你在“设置 → 模型服务 → 外部工具”中启用 Sciverse 或 MCP 服务器，模型在回答时可能会调用这些工具：

- 检索问题、工具参数与工具返回的结果会在本机代理与对应服务之间传输。
- Sciverse 会收到你的检索词；MCP 服务器会收到工具名与参数。它们各自的隐私政策适用。
- token 与请求头只保存在本机；设置页只显示是否已配置与尾号提示。
- 工具调用默认关闭，只有你明确启用的服务器会被使用。

## 网络请求

纸间只会在以下情况访问网络：

- 你主动发送对话时，连接你配置的模型服务地址。
- 你启用外部工具后，连接 Sciverse 或你添加的 MCP 服务器。
- 首次使用 OCR 或切换模型时，下载识别组件与模型文件。
- 你点击“检查更新”时，查询 GitHub Releases。

没有遥测、崩溃上报、统计或广告请求，也不会在后台轮询更新。

## 保存与删除

- “清空本篇对话与上下文”只删除当前文档的对话与上下文。
- “清空阅读数据”会删除阅读位置、对话、高亮、OCR 文本、最近文档与界面偏好。
- “清空阅读数据”不会删除磁盘上的 PDF 文件、模型服务密钥或已下载的 OCR 组件。
- 模型服务密钥可在“设置 → 模型服务”中单独清除；OCR 组件可在“设置 → 扫描件 OCR”中修复。
- 本地记录未加密；共用电脑时建议清空阅读数据。

## 安全边界

- PDF 内容视为不可信输入；模型不会执行文档中的指令。
- 本机代理只监听本机地址，并校验请求来源，拒绝跨站修改配置或消耗额度。
- API Key、Sciverse token 与 MCP 请求头只保存在本机，设置页仅显示是否已配置与尾号提示。
- 外部工具返回的内容按不可信数据处理，模型不会执行其中的指令。
- OCR 推理在本机完成，页面图片不会上传到云端 OCR。

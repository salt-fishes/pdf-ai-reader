# 隐私说明

纸间（Paper Reader）是本地优先的 PDF 阅读器。主 PDF 在浏览器中解析，阅读、搜索、高亮与 OCR
默认都在本机完成。只有你明确选择的内容才会发给你配置的模型服务。

## 本地处理

| 数据                                               | 位置                                                                    | 说明                                                                                  |
| -------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 主 PDF                                             | 浏览器内存                                                              | 通过 pdf.js 解析，不上传文件；关闭文档后释放。                                        |
| 阅读位置、对话、高亮、OCR 文本、页面尺寸、摘要分段 | IndexedDB                                                               | 未加密；可在设置中清空。                                                              |
| 最近文档缓存                                       | IndexedDB                                                               | 单个文件 ≤24MB，总量 ≤64MB，最多 8 条；超出预算时按最近使用淘汰缓存字节，记录仍保留。 |
| 界面偏好                                           | localStorage                                                            | 主题、助手形态、思考强度、上下文预算等。                                              |
| PDF 打开方式（可选）                               | `HKCU\Software\Classes` 与 `HKCU\Software\PaperReader`                  | 只有点击“注册为 PDF 打开方式”后才写入；可在设置中移除。                               |
| API Key、Base URL、模型允许列表                    | 本机代理（`server/data/provider.json`，桌面版在 `userData/data`）       | 不进入前端 bundle，不返回给浏览器。                                                   |
| OCR 运行时与模型                                   | `server/models`、桌面版 `userData/ocr-runtime` 与 `userData/ocr-models` | 首次下载后可离线使用；安全软件拦截时运行时回退到 `%TEMP%/paper-reader-ocr`。          |

## 发送给模型

只有以下内容会通过本机代理发给你配置的 OpenAI 兼容服务：

- 你选择的页码文本（当前页、全部页或页码范围）。
- 选中文字、跨页选择与引用。
- 整页截图、框选截图与上传的附件。
- 你的问题，以及对话历史窗口内的消息。

不会发送整份 PDF、未选择的页面、文件名或本地路径。云端是否保留请求内容由 provider
的条款与隐私政策决定；纸间不做额外转发。

## 网络请求

- AI provider 的 Base URL（由你配置）。
- OCR 运行时组件下载：默认当前版本的 GitHub Release 资产；下载后校验 SHA-256。
- OCR 模型下载：默认 GitHub Releases / HuggingFace，或你在设置中填写的镜像根地址。
- 手动检查更新：只在你点击“检查更新”时请求 GitHub Releases API，结果在内存缓存 5 分钟。
- 没有遥测、崩溃上报、统计或广告请求。

## 保存与删除

- 清空当前对话：只删除当前文档的对话与上下文。
- 清空所有本地数据：删除 IndexedDB、localStorage 与文档记录；不会删除磁盘上的 PDF
  文件，也不会删除本机代理中的 provider 配置与已下载的 OCR 模型。
- 代理默认只监听 `127.0.0.1`。局域网或公网部署需要自行增加认证、限流与 TLS。

## 安全边界

- PDF 内容视为不可信输入；模型不会执行文档中的指令。
- 本地代理会校验 Origin，拒绝跨站修改 provider 配置或消耗 token 的请求。
- API Key 只保存在服务端文件，设置页仅显示是否存在与尾号提示。
- OCR 推理在本机 worker 线程完成，图片不上传云端 OCR。

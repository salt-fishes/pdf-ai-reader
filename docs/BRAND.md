# 品牌与图标

## 标记

BrandMark 是纸间的唯一品牌几何：圆角页面轮廓 + 三条文本线 + 右下四角星。源文件：

- `build/icon.svg`：完整标记，用于 48px 以上的应用图标。
- `build/icon-small.svg`：去掉星芒、加粗文本线的小尺寸变体，用于 16/24/32px。
- `public/favicon.svg`：浏览器标签页，使用小尺寸几何。
- `build/icon.png`：512×512。
- `build/icon.ico`：16/24/32/48/64/128/256。

运行 `npm run icons` 可重复生成 PNG、ICO 与 favicon；不要手改生成物。

## 色板

| Token                    | 值                    | 用途                          |
| ------------------------ | --------------------- | ----------------------------- |
| `--brand-600`            | `#5b5bd6`             | 主按钮、active、聚焦、AI 入口 |
| `--brand-700`            | `#4545bd`             | 按下、链接、强调文字          |
| `--brand-100`            | `#ecebfb`             | 柔和背景、选中底色            |
| `--brand-a{NN}`          | `color-mix(...)`      | 透明度阶梯，组件按需引用      |
| `--teal`                 | `#0ea5b7`             | 信息、搜索命中                |
| `--amber`                | `#f59e0b`             | 高亮、OCR 提示                |
| `--success` / `--danger` | `#10b981` / `#dc4b4b` | 成功 / 危险                   |

品牌色只用于主操作、active、焦点环和 AI 入口；不要拿它表示成功或警告。

## 对比度

浅色主题：

- `--ink` 对白 15.9:1。
- `--muted` `#5f6675` 对白 5.76:1、paper 5.29:1、reading 4.57:1，满足 AA。
- `--faint` `#9aa0ac` 只用于图标、边框与分隔线，不用于文本。

夜间主题：正文 `--ink` `#e8eaf1`、次要文字 `--muted` `#a3aab9` 均高于 4.5:1；
`--faint` 同样只用于非文本元素。

## 尺寸与网格

- 24×24 viewBox，圆角页面从 `3.2, 2.4` 到 `20.8, 21.6`。
- 图标线宽在 24 viewBox 下为 2；14px 渲染约 1.17px，16px 约 1.33px。
- 界面图标四档：14（菜单/内联）、16（工具栏/设置导航）、18（对话框关闭）、20（空状态）。
- 品牌标记：22（顶栏）、28（空状态）、48（关于）。
- 16px 下使用简化变体，星芒不参与，避免糊成一团。

## 使用禁区

- 不要拉伸、旋转、描边或改变标记比例。
- 不要在标记上叠加文字或第二个星芒。
- 不要把品牌色替换成 provider 品牌色。
- 不要把 `--faint` 用于正文或元信息文字。

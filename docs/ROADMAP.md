# Roadmap

## 已完成

- P0：pdf.js 阅读器、悬浮窗/侧边栏、上下文、引用、TokenMeter、代理、IndexedDB、快捷键、E2E。
- P1：搜索高亮、目录、缩略图、BM25 智能筛选、框选截图、色彩模式、多会话、PP-OCRv6 OCR。
- 0.1 扩展：真实 DPR / 96dpi、KaTeX、截图 portal 预览、页面选择器、整本总结（map-reduce + 缓存）、高亮持久化/导出、跨页选择、正文链接、历史窗口、1M 软预算、模型服务 UI、费用单价、Electron 桌面壳。
- 0.2：虚拟化页面列表、密码 PDF、最近文档、引用回跳锚点、本地 OCR worker 与行级文本层、tiny/small/medium 模型、焦点陷阱。
- 0.4：OCR 运行时与模型改为按需下载，基础包不再携带 ONNX Runtime/OpenCV/canvas；组件包 SHA-256 校验与安全软件回退。
- 0.5：可选注册为 Windows PDF 打开方式；不自动修改默认应用，由系统设置确认。

## 下一步

### 1.0 之前

- DOCX 导入。
- OCR 画布命中框（词级矩形）。
- 双页 / 横向阅读。
- 桌面版代码签名与自动更新。

### 1.x

- 本地 Ollama / 多 provider 预设与连接诊断。
- 对话重命名、搜索、导出；引用句子级高亮。
- 可访问性：焦点陷阱、流式 `aria-live`、触控手势与捏合缩放。
- 性能：按可见区域绘制 detail canvas、KaTeX 按需加载、跨页画布内存上限。
- OCR 模型 SHA-256 校验与镜像白名单。

### P2

- 多文档对比、团队共享、配额与审计。
- PWA 离线、语音提问/朗读。
- 批注/评论与对话联动。
